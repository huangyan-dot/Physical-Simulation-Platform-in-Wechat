## 三、scoring.go 具体变更

### 第二批新增结构体

```go
// 评分目标
type photoelectricTarget struct {
    PlanckConst  float64  // 普朗克常数真值 (J·s)
    WorkFunction float64  // 逸出功真值 (J)
}
type frankHertzTarget struct {
    ExcitationPotV float64  // 激发电位真值 (V)
}
type gratingTarget struct {
    GratingConstM float64  // 光栅常数真值 (m)
}

// 读数
type photoelectricReading struct { FrequencyHz, StopV float64 }     // 光频率, 遏止电压
type frankHertzReading struct { VoltageV, CurrentA float64 }        // 加速电压, 板极电流
type gratingReading struct { OrderM int; AngleRad float64 }         // 衍射级次, 衍射角
```

### 第三批新增结构体

```go
// 评分目标
type oilDropTarget struct {
    Elementary float64  // 元电荷真值 (C)
}
type polarizationTarget struct {
    // 马吕斯定律验证，无需额外目标参数
}
type soundSpeedTarget struct {
    SpeedMS float64  // 声速真值 (m/s)
    FreqHz  float64  // 超声波频率 (Hz)
}

// 读数
type oilDropReading struct { VoltageV, DistanceM, TimeS float64 }   // 平衡电压, 下落距离, 下落时间
type polarizationReading struct { AngleDeg, Intensity float64 }     // 检偏器角度, 透射光强
type soundSpeedReading struct { OrderN int; PositionM float64 }     // 共振点序号, 反射镜位置
```

### 新增评分函数

| 函数 | 算法 |
|------|------|
| `ScorePhotoelectric` | (ν, V_s) 最小二乘线性拟合，斜率 = h/e，h = 斜率×e，与真值比对 |
| `ScoreFrankHertz` | I-V 数据按电压排序，窗口法找局部极大值（峰位），相邻峰电压差取平均 |
| `ScoreDiffractionGrating` | d = k·λ/sin(θ)，多组取平均 |
| `ScoreOilDrop` | q = (6πηrv·d)/V，每组 q 除以 e 取整量子数 n，q/n 反算 e 取平均 |
| `ScorePolarization` | 归一化后 |I_measured − I₀cos²(θ)| / I₀ 的平均偏差 |
| `ScoreSoundSpeed` | 逐差法求 λ/2，v = 2×(λ/2)×f |
| `applyGratingConfig` | user_config 覆盖 grating_const_m |
| `applySoundSpeedConfig` | user_config 覆盖 freq_hz |

所有评分函数均含 NaN/Inf/负值数据校验。
