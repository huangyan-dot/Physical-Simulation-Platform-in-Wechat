## 三、scoring.go 具体变更

### 新增结构体

```go
// 评分目标
type youngModulusTarget struct {
    YoungModulusPa float64  // 杨氏模量真值 (Pa)
    ForceN         float64  // 砝码重力 (N)
    LengthM        float64  // 金属丝原长 (m)
    DiameterM      float64  // 金属丝直径 (m)
    LeverArmM      float64  // 光杠杆臂长 (m)
    MirrorDistM    float64  // 镜尺距离 (m)
}

type hallEffectTarget struct {
    BFieldT     float64  // 磁感应强度 (T)
    ThicknessM  float64  // 样品厚度 (m)
    CarrierConc float64  // 载流子浓度真值 (m^-3)
}

type michelsonTarget struct {
    WavelengthNM float64  // 光波真值 (nm)
}

// 读数
type youngModulusReading struct { Load int; Reading float64 }  // 砝码序号, 望远镜读数(mm)
type hallEffectReading struct { CurrentA, VoltageV float64 }    // 工作电流(A), 霍尔电压(V)
type michelsonReading struct { N int; MirrorM float64 }         // 条纹数, 镜移距离(m)
```

### 新增评分函数

- `ScoreYoungModulus` -- 逐差法求平均伸长 Δn，反算 E = 8FnLD/(πd²b·Δn)，与真值比对
- `ScoreHallEffect` -- 由 V_H = IB/(nqd) 反算 n，多组取平均，与真值比对
- `ScoreMichelson` -- 由 λ = 2d/N 反算波长，多组取平均，与真值比对
- 三个函数均含 NaN/Inf/负值数据校验
- 三个 `applyXxxConfig` 函数支持前端 user_config 覆盖 DB target

## 四、seed.go 具体变更

### seedExperiments
新增 3 条种子：
- `young_modulus`：E=2.0e11 Pa, F=4.905N, L=1.0m, d=0.5mm, b=70mm, D=1.5m
- `hall_effect`：B=0.3T, d=0.5mm, n=1e21 m^-3
- `michelson`：λ=632.8nm (He-Ne 激光)

### seedLevels（逻辑重写）
- **旧逻辑**：`if count > 0 { return }` -- 已有任意关卡就全部跳过，无法增量新增
- **新逻辑**：按 `order_no` 逐个检查，不存在的补建，前置关卡指向 `order_no-1` 的关卡
- 这样重启后端即可自动补建 L4-L6，不影响已有 L1-L3 的数据和进度
